## Run locally
```powershell
npm.cmd install
npm.cmd run dev
```
Open http://localhost:3000 (or the port Next.js shows).

## Put it online with a public link
1. Create a free account at Vercel.
2. Import this project from GitHub **or** upload/deploy the project folder using Vercel CLI.
3. Vercel will give you a public HTTPS link such as `https://your-site.vercel.app`.
4. Send that link to anyone; they can open the portfolio from anywhere.

`vercel.json` is included for Next.js deployment.
